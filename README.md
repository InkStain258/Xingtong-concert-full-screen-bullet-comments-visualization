# 从虚拟里拿出一颗真心 · 星瞳弹幕数据可视化

> 「从虚拟里拿出一颗真心」—— 星瞳周年演唱会直播弹幕大数据可视化

## 项目简介

这是一个精美的静态网站，对**星瞳（Xingtong）**的一场特别直播（周年演唱会回放）的弹幕数据进行全面可视化分析。

**星瞳**是QQ炫舞系列虚拟代言人，国内知名虚拟偶像/VTuber，粉丝称"小星星"。本项目收集了直播全程共 **56,402 条** 真实弹幕数据，用数据的方式记录下小星星们对瞳宝宝最真实的情感。

**数据概览：**
- 📊 总弹幕数：56,402 条
- ⏱️ 直播时长：约 186.7 分钟
- 🔥 峰值弹幕速率：657 条/分钟（第43分钟）
- 💬 平均弹幕速率：302 条/分钟
- 💙 最高频弹幕：`mua`（出现 2521 次）

## 本地预览

### 方法一：直接打开（推荐）

由于所有数据已**内嵌在 HTML 文件**中，可以直接用浏览器打开：

```bash
# 双击打开，或在终端执行
open dist/index.html       # macOS
start dist/index.html      # Windows
xdg-open dist/index.html   # Linux
```

### 方法二：本地 HTTP 服务器

为了获得更好的加载体验（避免浏览器CORS限制），推荐使用本地服务器：

```bash
# Python 3
cd dist/
python -m http.server 8080

# Node.js（需安装 http-server）
npx http-server dist/ -p 8080

# 然后访问 http://localhost:8080
```

## GitHub Pages 部署

### 方法一：部署 dist 目录（推荐）

1. **Fork 本仓库** 到你的 GitHub 账号

2. **打开仓库设置**：进入仓库页面 → 点击 `Settings`

3. **配置 Pages**：
   - 左侧找到 `Pages` 选项
   - `Source` 选择 `Deploy from a branch`
   - `Branch` 选择 `main`（或 `master`），目录选择 `/dist`
   - 点击 `Save`

4. **等待部署**：约 1-3 分钟后，页面地址会显示在 Pages 设置页面
   - 格式：`https://<你的用户名>.github.io/<仓库名>/`

5. **访问网站**：打开上述链接即可看到可视化网站 🎉

### 方法二：直接上传 dist 目录内容

1. 在 GitHub 新建仓库
2. 将 `dist/` 目录中的所有文件（`index.html`、`data/` 文件夹）上传到仓库根目录
3. 在 Settings → Pages 中选择 `main` 分支的 `/root` 目录
4. 保存并等待部署

> **注意**：所有弹幕数据已内嵌到 `index.html` 的 JavaScript 中，无需服务器支持，可直接作为静态页面运行。

## 数据说明

- **原始数据**：来自星瞳直播弹幕录制（`p1.txt`：19,878条，`p2.txt`：36,524条）
- **数据格式**：`时间戳(ms):弹幕内容`
- **处理方式**：Python脚本 `scripts/process_data.py` 进行数据清洗、词频统计、情感分类
- **隐私保护**：原始数据中不含用户ID，只有弹幕内容和时间戳
- **注意**：原始 `.txt` 数据文件不包含在本仓库中（体积较大），仅包含处理后的 JSON
