### 互动功能

- 🎛️ **时间轴时段筛选**：一键切换查看全程/前60分钟/中段/后段
- 🔍 **词汇搜索**：在词云旁输入词汇，即时查看出现频次
- 🏷️ **情感筛选**：名句区按爱意/欢笑/应援/感动分类筛选
- 📌 **点击高亮**：点击时间轴数据点查看该分钟详细信息
- 🖱️ **悬停详情**：所有图表支持鼠标悬停Tooltip
- 🔬 **弹幕分析器**（`analyzer.html`）：上传自定义弹幕txt文件（支持 `timestamp:content` 格式），纯前端即时分析。**11大可视化**：趋势/内容/摘要/排行四大分区编排。**v7新增**：TF-IDF智能时段摘要、弹幕长度直方图、弹幕浓度散点图。**v8修复**：峰值标注定位、散点图排版、时段摘要时间显示、弹幕解析格式（行首数字=时间戳，非弹幕内容）。支持导出Markdown报告，含星空粒子背景、交错卡片入场动画、section锚点导航。
- 📸 **分享海报**：主页面和分析器均支持一键生成精美数据海报，Canvas渲染星空主题设计，包含核心统计数据和装饰元素，可直接下载PNG。
- 📌 **峰值事件标注**：时间轴图表上标注关键事件时刻（直播热场、弹幕峰值、安可环节等），分析器自动检测Top-5峰值并标注。v7修复时段筛选标注不更新bug。
- 🔍 **词云→弹幕联动**：点击词云词语打开侧边抽屉，列出所有包含该词的真实弹幕（带时间戳、关键词高亮、情感标签），最多200条。
- 🖼️ **弹幕照片墙**：全屏网格视图，弹幕按情感类别着色平铺，hover放大查看详情。

```bash

直接打开 dist/index.html  或  dist/analyzer.html

# 方法二：使用本地服务器（如需完整功能）
```

## 🌐 部署到 GitHub Pages

### 方法一：使用 dist 目录部署（推荐）

1. **新建 GitHub 仓库**（公开仓库）

2. **上传文件**：将 `dist/` 目录下的所有文件上传到仓库根目录
   ```
   index.html
   README.md
   data/（整个目录）
   ```

3. **开启 GitHub Pages**：
   - 进入仓库 → **Settings**
   - 左侧菜单找到 **Pages**
   - Source 选择 **main** 分支，目录选 **/ (root)**
   - 点击 **Save**

4. **访问网站**：等待约1-2分钟后，访问 `https://你的用户名.github.io/仓库名`

### 方法二：使用 GitHub Desktop

1. 在 GitHub Desktop 新建仓库
2. 将 `dist/` 内容复制到仓库文件夹
3. 提交并推送
4. 在 GitHub 网页端开启 Pages（步骤同上）

## 📝 数据说明

- **数据来源**：星瞳五周年演唱会RE直播弹幕（2025年）
- **数据文件**：`p1.txt`（19,878条）+ `p2.txt`（36,524条）

- **数据处理**：Python脚本进行时序聚合、词频统计、情感分类
- **情感分类**：基于关键词词典+模式回退的优先级匹配，新版11类细分体系（v9升级："其他"占比从64%降至32%）
